# Employees CRUD (gRPC)

Учебный проект: учёт сотрудников, отделов, должностей и задач. Клиент на Avalonia UI, сервер на ASP.NET Core + gRPC, база — PostgreSQL.

## Технологии

- C#
- .NET
- gRPC (Grpc.AspNetCore, Grpc.Net.Client)
- PostgreSQL
- Npgsql
- Avalonia UI
- ReactiveUI
